Quarto + Closeread + Folium Story Map Site Improvement Checklist

High Priority Issues

1. Quarto YAML Configuration and Closeread Syntax

    • Action: Add proper closeread-html configuration to _quarto.yml
    • Example: Add closeread-html: section with appropriate settings

2. Folium Map Integration

    • Action: Pre-process and cache map data where possible to improve load times
    • Example: Create a separate script for map generation with caching

3. CSS/HTML Layout Conflicts

    • Action: Add more responsive units like max-width and use clamp() for better scaling
    • Example: Replace height: 75vh with responsive units

Medium Priority Issues

1. Code Structure and Maintainability

    • Action: Format the Python code with consistent indentation and add documentation
    • Example: Add function docstrings and improve code comments

2. Map Navigation Experience

    • Action: Add loading indicators or visual cues during view transitions
    • Example: Add a “Loading…” overlay during view changes

3. Accessibility

    • Action: Add proper ARIA labels and semantic HTML
    • Example: Add aria-label attributes to important elements

4. Error Handling

    • Action: Add try/catch blocks for file operations and data processing
    • Example: Wrap file loading operations with error handling

Low Priority Issues

1. Code Documentation

    • Action: Create a README.md with setup instructions
    • Example: Add section on setting up the conda environment, installing dependencies, etc.

2. Performance Optimization

    • Action: Implement data caching and pre-processing steps for better performance
    • Example: Save processed GeoJSON to intermediate files that can be reused

3. Map Layer Management

    • Action: Add a layer control panel or similar interface
    • Example: Implement a layer control UI for users to interact with different map layers

4. Mobile Responsiveness

    • Action: Add media queries for mobile optimization
    • Example: Add @media queries to adjust spacing and sizing for smaller screens
